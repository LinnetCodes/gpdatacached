# 功能完整性审查 - 整改进度

## 工作原则

- 每次对话只解决一个问题，不贪多
- 每个问题先彻底理解、讨论出完善方案后再动手改
- 审查员也可能犯错，不盲信报告中的所有问题和建议
- 尊重提出的问题，但客观分析其是否为真正需要解决的问题
- 按紧急程度、复杂度和相关性建立优先级
